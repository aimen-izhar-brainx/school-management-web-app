# T-025: Wire MyTimetablePage for teachers and students (frontend)
- Milestone: M4
- Depends on: T-024
- Use cases: UC-18, UC-19, UC-20, UC-21

## Goal
Replace `MyTimetablePage`'s mock data with a real call to `GET /timetable/me` (T-024), rendering a teacher's combined schedule or a student's section schedule, fully read-only.

## Definition of Done
- [x] AC-18.1 Given a teacher has entries in two different sections, when the page loads, then both appear on one grid, each cell showing subject + section (e.g. "Mathematics — Grade 5-A").
- [x] AC-18.2 Given a teacher has no entries yet, when the page loads, then it shows "No classes scheduled yet." rather than an error.
- [x] AC-18.3 Given this is a read-only view, when rendered, then no edit/add/remove controls are present anywhere on the page.
- [x] AC-19.1 Given a student's section has entries, when the page loads, then the grid shows subject + teacher per cell, matching the admin-built timetable exactly.
- [x] AC-19.2 Given this is a read-only view for students too, then no edit/add/remove controls are present.
- [x] AC-19.3 Given the section's timetable changes later, when the student reloads the page, then it reflects the latest version.
- [x] UC-19-E1 Given a student's section has no entries yet, when the page loads, then it shows "Your class's timetable hasn't been set up yet." rather than an error.
- [x] AC-20.1 Given a student has no section assigned, when the page loads, then it shows "You haven't been assigned to a class section yet. Contact your school admin." rather than a blank grid or an error.
- [x] UC-20-E1 Given the admin assigns the student to a section while this page is open, then reloading the page shows the real timetable (no live push required).
- [x] All tests pass. Reviewer approved. Verifier passed.
