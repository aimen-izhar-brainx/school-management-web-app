## Summary

Stack: NestJS 12 backend and React 19 frontend, in one repo. The change wires the frontend to the existing `/teachers` and `/students` APIs. It adds a paginated People directory (`PeopleListPage`) with delete, a `lib/people.ts` API client, API-backed create forms for teachers and students in `AdminCreatePage`, and `patch`/`delete` helpers on `api`. The dashboard Students card now opens the directory and a Teachers card is new. The frontend request and response shapes match the backend DTOs and `PaginationDto` (page/limit, `{ data, meta }`, 204 on delete). I found no correctness or security defects. Re-review: all three low-severity findings are now fixed.
