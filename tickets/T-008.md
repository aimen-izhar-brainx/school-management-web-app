# T-008: De-duplicate timetable grid rendering
- Milestone: M3
- Depends on: T-004
- Use cases: UC-04

## Goal
Extract the duplicated `formatTime` helper and the break-row/grid-cell rendering shared between `TimetablePage.tsx` and `MyTimetablePage.tsx` into shared helpers/components, with no change in displayed data or styling.

## Definition of Done (copied from use cases)
- [x] AC-04.1 Given a period marked `isBreak`, when either page renders that row, then it spans all day columns with the same break styling (amber background, coffee icon, time range), via shared row logic.
- [x] AC-04.2 Given a non-break period with no entry for a day, when TimetablePage renders the cell, it shows "Free period" in the dropdown; when MyTimetablePage renders the same empty slot, it shows the dashed "Free" placeholder — both via the shared `formatTime` helper.
- [x] AC-04.3 Given a period's start/end time (e.g. "14:30"), when formatted by the shared `formatTime` helper, then it displays as "2:30 PM" identically on both pages (currently duplicated verbatim in each file).
- [x] AC-04.4 Given a teacher viewing MyTimetablePage whose slots span multiple sections, then each cell's caption shows the correct section label (unchanged matching-by-name logic).
- [x] UC-04-E1 Given an empty `SECTION_OPTIONS` array, when MyTimetablePage computes a student's schedule, then it doesn't crash.
- [x] UC-04-E2 Given a teacher's name doesn't match any seed teacher, when MyTimetablePage loads, then it falls back to `TEACHERS[0]`, exactly as today.
- [x] UC-04-E3 Given all periods are removed on TimetablePage, when the periods list renders, then "No periods defined yet." still appears.
- [x] All tests pass. Reviewer approved. Verifier passed.

## Technical notes
- Files: `frontend/src/components/TimetablePage.tsx`, `MyTimetablePage.tsx` — both currently define an identical `formatTime(time: string): string` function verbatim; move it to `frontend/src/data/timetable.ts` (where `sectionLabel`/`teacherName` already live) or a new `frontend/src/lib/time.ts`.
- The break-row `<tr>` markup (amber background + `Coffee` icon + time range spanning `DAYS.length + 1` columns) is near-identical between the two files — extract to a shared row component taking `period` as a prop.
- `TimetablePage` is editable (subject/teacher `<select>`s) while `MyTimetablePage` is read-only — only extract the parts that are genuinely identical (time formatting, break rows), not the editable cell logic.
- Depends on T-004 since it edits the same two files T-004 already migrated to `DashboardShell`.
- Can run in parallel with T-007 — disjoint files.
