# T-027: Subject rename + delete UI (frontend)
- Milestone: M2
- Depends on: T-019, T-026
- Use cases: UC-22, UC-12 (partial)

## Goal
Add Rename and Delete controls to the subject catalog on `ClassesPage`, using T-026's endpoints and following the same rename/confirm-delete patterns as the class list (T-014).

## Definition of Done (copied from use cases)
- [x] AC-22.1 Given a valid, unique new name, when saved, then the new name shows immediately in the catalog, in every class's subject list and in every timetable cell that uses it, and it persists after reload.
- [x] AC-22.2 Given the name is cleared to empty, when saved, then shows "Please enter a subject name." and keeps the original name.
- [x] AC-22.3 Given the new name already belongs to another subject (case-insensitive), when saved, then shows "This subject already exists." and the rename is not applied.
- [x] AC-22.4 Given a subject not assigned to any class, when Admin confirms delete, then it disappears from the catalog and does not reappear after reload.
- [x] AC-22.5 Given a subject assigned to one or more classes, when Admin confirms delete, then shows "This subject is in use and can't be deleted." and nothing is removed (same rule as UC-09-E1).
- [x] AC-22.6 Given Admin cancels the delete confirmation, then the subject is not deleted.
- [x] UC-22-E2: Subject was already deleted by another session → shows "This subject no longer exists." and refreshes the catalog.
- [x] AC-12.2 Given Teacher/Student viewing the Classes page, then none of the M2 write controls (add section, add subject, assign teacher, assign student) are shown or enabled.
- [x] All tests pass. Reviewer approved. Verifier passed.

## Technical notes
- Files: `frontend/src/components/SubjectCatalogManager.tsx` (new; the admin "Manage subjects" list), mounted from `ClassSubjectsPanel.tsx`, which owns the catalog state; tests are in `ClassesPage.test.tsx`. (The ticket originally said `ClassesPage.tsx`, but the catalog moved to `ClassSubjectsPanel.tsx` in T-019.)
- AC-22.1 here covers the catalog and the class subject lists. Refetch or update both after a rename. Timetable cells are checked in T-023.
- Show the backend's `ApiError.message` for the 400 responses. On a 404, show "This subject no longer exists." and refetch `GET /subjects`.
- Rename/Delete controls are hidden for non-admins, the same as the other M2 write controls (AC-12.2).
