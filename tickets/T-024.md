# T-024: GET /timetable/me endpoint (backend)
- Milestone: M4
- Depends on: T-022, T-017, T-028
- Use cases: UC-18, UC-19, UC-20, UC-21, UC-23 (partial)

## Goal
Add a single endpoint that returns the caller's own timetable: for a teacher, all their taught slots across every section; for a student, their assigned section's full timetable; scoped strictly to the caller.

## Definition of Done
- [ ] AC-18.1 Given a teacher has entries in two different sections, when they call this endpoint, then both are returned, each including subject + section name.
- [ ] AC-18.2 Given a teacher has no entries at all, when they call this endpoint, then it returns an empty result, not an error.
- [ ] UC-18-E1 Given a teacher can never be double-booked (T-022's constraint), then the response never contains two entries at the same day + period.
- [ ] AC-19.1 Given a student's section has timetable entries, when they call this endpoint, then the section's full grid (subject + teacher per slot) is returned, matching the admin-built timetable exactly.
- [ ] UC-19-E1 Given a student's section has no timetable entries yet, when they call this endpoint, then it returns an empty grid, not an error.
- [ ] AC-20.1 Given a student has no `sectionId` assigned, when they call this endpoint, then the response clearly indicates "no section assigned" (e.g. a distinct field/flag) rather than an error or a misleading empty grid.
- [ ] AC-21.1 Given Teacher A calls this endpoint, when the response returns, then it never includes another teacher's slots.
- [ ] AC-21.2 Given Student A calls this endpoint, when the response returns, then it never includes another section's timetable.
- [ ] AC-21.3 Given Teacher or Student call any M3 write endpoint (T-021/T-022) directly, then responds 403 Forbidden, consistent with UC-17.
- [ ] AC-23.3 (My Timetable part, completed here) Given students were assigned to those sections, when the class is deleted, then the student accounts still exist with no section; on "My Timetable" they see the UC-20 message. (Backend side: a student whose class was deleted gets the same "no section assigned" response as AC-20.1.)
- [ ] UC-21-E1 Given no token or an expired token, when calling this endpoint, then responds 401 Unauthorized.
- [ ] All tests pass. Reviewer approved. Verifier passed.

## Technical notes
- In `backend/src/timetable/`, add `GET /timetable/me` (`@UseGuards(JwtAuthGuard)`, any authenticated role). Branch on `request.user.role`:
  - `teacher` → query `TimetableEntry` where `teacherId = request.user.sub`, joined with `Section`/`Class` names.
  - `student` → look up the caller's `User.sectionId` (from T-017); if null, return the "no section assigned" shape (AC-20.1); otherwise return that section's full `TimetableEntry` set.
  - `admin` / `parent` → out of scope for this ticket. Don't add a role restriction here: T-031 owns the `@Roles('teacher', 'student')` change and its 403 tests (AC-25.2).
- This is a read endpoint; the actual write protection (AC-21.3) is already enforced by T-021/T-022's guards — this ticket just needs a test confirming it, not new guard code.
