# T-010: Add backend oxlint config
- Milestone: M5
- Depends on: none
- Use cases: UC-06

## Goal
Add `.oxlintrc.json` to `backend/` (currently has a lint script but no config, so it runs with defaults only) and fix any violations it surfaces, mirroring the frontend's config where applicable.

## Definition of Done (copied from use cases)
- [x] AC-06.1 Given the new `.oxlintrc.json`, when `npm run lint` runs against `backend/src` and `backend/test`, then it completes with no errors on the current codebase.
- [x] AC-06.2 Given the config mirrors the frontend's plugin set where applicable (typescript, oxc — react plugin omitted, no React in backend), when linting, then TypeScript-specific rules are active.
- [x] UC-06-E1 Given a deliberately introduced unused variable in a backend file, when `npm run lint` runs, then it reports an error for it (proves the config actually enforces rules).
- [x] All tests pass. Reviewer approved. Verifier passed.

## Technical notes
- Reference: `frontend/.oxlintrc.json` currently has `"plugins": ["react", "typescript", "oxc"]` with `react/rules-of-hooks` and `react/only-export-components` rules — backend's config should use `["typescript", "oxc"]` (no `react` plugin, no `react/*` rules).
- Backend's `package.json` already has `"lint": "oxlint src/ test/"` — no changes needed there, just add the missing config file.
- This is independent of all frontend tickets and can run at any point — no dependency needed.
