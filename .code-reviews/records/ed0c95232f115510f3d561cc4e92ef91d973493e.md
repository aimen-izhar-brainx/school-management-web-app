## Summary

Adds the Class model + migrations and a `classes` NestJS module (list for any authenticated user; create/rename/delete admin-only via JwtAuthGuard + RolesGuard), a trimming/validating DTO, and an integration spec against real Postgres. Re-review: `Class.name` is now `citext` (new migration + `@db.Citext` + `postgresqlExtensions`), so the unique index is case-insensitive at the DB level, and a concurrent mixed-case race test was added. The spec no longer uses `as any` casts. Stack: NestJS (Prisma). Ticket/STATUS markdown changes are doc-only.
