# T-003: Migrate dashboard-level pages to DashboardShell
- Milestone: M1
- Depends on: T-002
- Use cases: UC-01

## Goal
Replace the duplicated header markup in `AdminDashboardPage`, `RoleHome`, `ProfilePage`, `AdminCreatePage`, and `ClassesPage` with the shared `DashboardShell` from T-002, with no visible or behavioral change.

## Definition of Done (copied from use cases)
- [x] AC-01.1 Given any of these 5 pages, when it loads, then the header shows the GraduationCap icon + "Brainx School" text in the same position/style as before the refactor.
- [x] AC-01.2 Given `ProfilePage`/`AdminCreatePage`/`ClassesPage` (sign-out-only pages), when rendered after the refactor, then they still show only Sign out.
- [x] AC-01.3 Given `AdminDashboardPage`/`RoleHome`, when rendered after the refactor, then they still show both Profile and Sign out buttons.
- [x] AC-01.4 Given any of these pages, when the user clicks "Sign out", then the session is cleared and the login screen is shown, even if the backend `/auth/logout` request fails.
- [x] AC-01.5 Given `ProfilePage`/`AdminCreatePage`/`ClassesPage`, when loaded, then "Back to dashboard" still returns to the correct role dashboard.
- [x] UC-01-E2 Given the user double-clicks "Sign out" rapidly, when both clicks register, then nothing throws (sign-out is idempotent).
- [x] UC-01-E3 Given unsaved input in `AdminCreatePage`'s form, when "Back to dashboard" is clicked, then the input is discarded without a confirmation prompt (matches current behavior).
- [x] All tests pass. Reviewer approved. Verifier passed.

## Technical notes
- Files: `frontend/src/components/AdminDashboardPage.tsx`, `RoleHome.tsx`, `ProfilePage.tsx`, `AdminCreatePage.tsx`, `ClassesPage.tsx`.
- `App.tsx` passes `onBack`/`onSignOut`/`onOpenProfile` callbacks into these already — only the internal markup changes, not the props each component accepts from `App.tsx`.
- `ProfilePage.tsx` and `AdminCreatePage.tsx` are the two files T-006 (email validator) will also touch — land this ticket first to avoid rebasing form-internals changes against header changes.
